# Archived experiments

Scripts and feature sets from earlier project stages, kept for the report and
for reproducibility. They target the code layout of the git tag they were
written at and are not maintained against the current agent:

| file | stage | notes |
|---|---|---|
| `featuresv2.py` | week 2 | 5-component coin/walkability features (first shared feature set) |
| `featuresv3.py`, `test_q_agent_features.py` | week 4 | 22-component set; too large for a tabular learner, superseded by v4 |
| `run_symmetry_ablation.py`, `analyze_symmetry.py` | week 2 | D4 canonicalisation on/off experiment and its plot |
| `feature_ablation.py`, `evaluation_features.py` | week 4 | feature-set comparison runners |

To rerun one, check out the tag it was written at (`features-v1`, `w3-milestone`, ...).
